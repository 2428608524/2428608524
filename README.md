# 相似K线股票检索脚本

输入一只 A 股股票代码（如 `600519`），脚本会：

1. 从东方财富 API 拉取该股票最近约两个半月（日K，默认 55 个交易日）数据；
2. 从 A 股候选池中拉取同样区间 K 线；
3. 基于 K 线形态特征（实体、上下影线、日收益、成交量）计算相似度；
4. 输出最相似股票代码列表。

## 依赖

- Python 3.9+（仅标准库，无需额外安装）

## 用法

```bash
python stock_pattern_matcher.py 600519 --topn 10 --lookback-days 55 --max-candidates 500 --workers 16
```

参数说明：

- `code`：目标股票代码（6 位 A 股代码）
- `--topn`：输出前 N 只相似股票
- `--lookback-days`：回看交易日数量（默认 55，约两个半月）
- `--max-candidates`：候选股票数量上限（越大越慢）
- `--workers`：并发线程数

## 说明

- 数据接口为东方财富公开接口，接口字段可能会变动；
- 当前使用余弦相似度匹配形态，可按需替换为 DTW 等时序算法；
- 若要提高准确度，建议提高候选数量并做行业/市值分层过滤。
